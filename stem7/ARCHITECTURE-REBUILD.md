# STEM 7 — технічний аудит і план переходу (10.10.2026)

## Незмінні умови
- Мова інтерфейсу та власних уроків: українська.
- Публічна адреса залишається `https://romarepyah.github.io/tabata-forge-pages/stem7/`.
- Працює на телефоні Samsung та iPad, без горизонтального скролу.
- Зберегти `localStorage` ключі `stem7_v2`, `stem7_v2_backup`; перед міграцією експортувати й протестувати імпорт.
- Без серверних секретів у GitHub Pages. Offline PWA для статичних уроків і локальної практики.
- Не переносити чужий контент без перевірки ліцензії.

## Результат дослідження open source
1. Mathigon Textbooks: структура уроків `content.md` + `functions.ts` + `styles.scss` + `hints.yaml`. Це **приклад архітектури та педагогіки**, а не готовий пакет для прямого копіювання: у package.json `license: UNLICENSED`, `private: true`; в README — copyright. Не копіювати їхні тексти, графіку або вихідний код уроків без дозволу. URL: https://github.com/mathigon/textbooks
2. Mathigon Euclid.js: окремий MIT-пакет для геометрії та SVG. Оцінити імпорт у новий фронтенд після тесту bundle size і touch. URL: https://github.com/mathigon/euclid.js
3. Khan Perseus: MIT, React-based exercise renderer/grader; придатний як потенційний компонент, але не plug-and-play для нашого монолітного HTML. Потрібні Vite/React, тест збірки й ліцензій. URL: https://github.com/Khan/perseus
4. Kolibri: розглядати як референс для offline/learner progress, **не** вбудовувати як JS бібліотеку. URL: https://github.com/learningequality/kolibri

## Архітектура
- Зберегти публічний шлях `/stem7/`; поточну сторінку не видаляти, доки нова не пройшла тест.
- Новий фронтенд — статична Vite збірка (з можливістю React для Perseus), результат `dist/` публікується в ту саму папку `stem7/` у Pages.
- Дані уроків зберігати **окремо від компонентів**: `curriculum/*.json`, з `topicId`, prerequisites, learningOutcomes, references, lesson blocks, exercises, rubric, misconceptions, video metadata.
- Урок не обмежувати фіксованою послідовністю блоків: типізовані компоненти `explanation`, `workedExample`, `interactivePlane`, `proof`, `experiment`, `guidedPractice`, `independentWork`, `assessment`, `video`.
- Схема завдань: `id`, `topicId`, `concepts`, `prompt`, `widget`, `answerSpec`, `feedbackByError`, `difficulty`, `variantSeed`. Не генерувати нову відповідь без зміни умови.
- Mastery лише за нові незалежно розв'язані завдання; помилки формують чергу повторення за `conceptId`.
- Творчі відповіді мають `needsParentReview`; цифрові задачі оцінюються локально.
- Генеративний AI — тільки через окремий захищений backend; до підключення не називати евристики AI.

## Еталонний урок: координатна площина
- Підручникове означення та зображення системи координат, масштаб, знаки, чверті.
- Дотикова координатна сітка з доступністю через клавіатуру.
- Переміщення точки і миттєвий зворотний зв'язок про x/y.
- Самостійна побудова багатокутника за списком координат.
- 8–12 концептуально різних завдань (одна відповідь, кілька, координати, побудова, помилки).
- Змішане застосування: графік шляху від часу.
- Відео — лише після ручної перевірки точного URL, мови, відповідності темі й доступності.
- Перевірка на Android та iPad; не змінювати старі ключі збереження.

## Статус
Цей файл — дослідницький і технічний план, **не реалізація** міграції. Поточний застосунок лишається доступним за попередньою адресою. Не стверджувати, що Mathigon або Perseus вже інтегровано.
